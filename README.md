# scoop-bitbucket-cli

Scoop bucket for [`bt`](https://github.com/arogan178/bitbucket-cli), a `gh`-style CLI for Bitbucket Cloud and Data Center.

## Install

```powershell
scoop bucket add bitbucket-cli https://github.com/arogan178/scoop-bitbucket-cli
scoop install bt
```

## Upgrade

```powershell
scoop update bt
```

## About

`bt.json` is generated by GoReleaser on each `bt` release. Don't edit it by hand. Report issues with `bt` itself in the [main repository](https://github.com/arogan178/bitbucket-cli/issues).
